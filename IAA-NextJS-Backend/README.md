# IAA integrated backend — Next.js and PostgreSQL/PostGIS

Start with [START_HERE.md](START_HERE.md).

WP1: released GIS layers/features, nearby infrastructure and projects, district environmental/crop/land/irrigation data, universal search, metadata, comparisons, CSV exports, knowledge and policies.

WP2: expiring capability-protected assessments, scenario revisions, immutable/idempotent runs, method/data version pinning, configurable MCDA, hosting checks, model/scheme/retrofit rules, spatial facility proximity, geometric shading and cashflow arithmetic.

WP3: organisation/project access, forms/indicators/obligations, all canonical draft fact resources, typed/repeating/conditional answers, complete payload hashing, validation, independent review, corrections, approved restricted reporting and release revocation.

Administration: master data, governed dataset versions, XLSX/CSV/JSON imports with quarantined rows, restricted evidence files with manual review, user provisioning, memberships, audits, queries and in-app reminders.

Scientific and operational boundaries are explicit in [docs/DELIVERY_STATUS.md](docs/DELIVERY_STATUS.md). Source code delivery is not a claim of live production acceptance or approval of partner methods.
